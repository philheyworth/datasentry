Scanner Deployment Snippet

Pass these environment variables when deploying the scanner to a customer machine. Use --customer-id and --customer-name to group machines by customer in the dashboard.

# Windows — set these then run the .exe
set DATASENTRY_API_URL=https://your-api.example.com
set DATASENTRY_API_KEY=dsk_your_key_here
set DATASENTRY_CUSTOMER_ID=your-customer-id
set DATASENTRY_CUSTOMER_NAME=Customer Name
datasentry-scanner.exe

# macOS / Linux
DATASENTRY_API_URL=https://your-api.example.com \
DATASENTRY_API_KEY=dsk_your_key_here \
DATASENTRY_CUSTOMER_ID=your-customer-id \
DATASENTRY_CUSTOMER_NAME="Customer Name" \
./datasentry-scanner --cli

Windows Agent Installer

Downloads a ZIP containing DataSentry.exe, a pre-configured datasentry.cfg, and a one-click install.bat. Run install.bat on each machine — no manual configuration needed.

Installation Steps
1. Click Download Agent ZIP above
2. Copy the ZIP to each Windows machine you want to scan
3. Extract the ZIP and double-click install.bat
4. The scanner runs, submits results, and exits — no reboot needed
5. Results appear in this dashboard within seconds
