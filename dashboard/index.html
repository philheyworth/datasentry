Process

Up and running in three steps.

No infrastructure to configure, no agents to manage long-term. DataSentry is designed for IT teams and MSPs who need answers fast.

Step 01
🕐

Register & onboard

Log into the DataSentry portal, create a customer record, and download their pre-configured MSI installer. The installer embeds the API key automatically — no manual setup needed on the endpoint.

Step 02
💾

Install the agent

Run the MSI on each machine — it installs in seconds, creates a Start Menu shortcut, and kicks off the first scan automatically. Deploy via Group Policy, Intune, or Jamf for fleet-wide rollout.

Step 03
✅

Review in the portal

Results appear in the compliance portal instantly. Browse findings by machine, export reports, track remediation, and schedule the next scan — all from one place.
